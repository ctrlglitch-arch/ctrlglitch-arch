## Run the donut on Windows
1. Install Python 3 if it is not already installed.
2. Put `spinning_donut.py` in a folder.
3. Open that folder in File Explorer.
4. Click the address bar, type `cmd`, and press Enter.
5. Run:
   `python spinning_donut.py`
6. Stop it with `Ctrl+C`.

If `python` isn't recognized, try:
   `py spinning_donut.py`

## Update your GitHub profile
1. Download and extract the ZIP.
2. Open your profile repository: https://github.com/ctrlglitch-arch
3. Edit its `README.md`, replace the contents with the supplied `README.md`, then commit.
4. The live donut code runs locally in a terminal; GitHub README Markdown cannot execute Python code or run terminal animation. If you want it visible on the profile, record the terminal animation or convert frames to a GIF separately, but the source animation itself is real-time code.
